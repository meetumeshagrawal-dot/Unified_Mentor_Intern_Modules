# Module 1: Vectors Using NumPy

This module introduces NumPy vectors and demonstrates how to create them, access their elements, and perform common mathematical operations.

## Topics Covered

- Creating NumPy arrays and vectors
- Checking an array's shape, dimensions, and data type
- Indexing, slicing, and filtering vector values
- Performing arithmetic and element-wise operations
- Calculating sums, means, minimums, and maximums
- Computing dot products and Euclidean length
- Converting temperatures from Celsius to Fahrenheit
- Solving basic vector practice problems

## Requirements

- Python 3
- NumPy

Install NumPy if needed:

    python -m pip install numpy

## How to Run

Open `Module_1_worksheet_completed.ipynb` in Jupyter Notebook, JupyterLab, or Visual Studio Code. Run the cells in order, from top to bottom.

## Practice Problems

The notebook includes worked solutions for:

1. Creating a vector and calculating its sum and mean
2. Calculating item costs from prices and quantities
3. Selecting and counting values above the mean

Assertions in the notebook check that selected results match the expected values.
