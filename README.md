
# Module 1: Vectors Using NumPy

This notebook introduces one-dimensional NumPy arrays (vectors) and demonstrates common operations through examples and solved practice problems.

## Topics Covered

- Creating NumPy arrays and vectors
- Inspecting array shape, dimensions, and data type
- Indexing, slicing, and filtering values
- Vector arithmetic and element-wise operations
- Summary operations: sum, mean, minimum, and maximum
- Dot products and Euclidean vector length
- Converting Celsius temperatures to Fahrenheit
- Applying vector operations to simple practice problems

## Requirements

- Python 3
- NumPy

Install NumPy if it is not already installed:

```bash
python -m pip install numpy
```

## How to Run

Open `Module_1_worksheet_completed.ipynb` in Jupyter Notebook, JupyterLab, or Visual Studio Code. Run the cells from top to bottom.

## Practice Problems

1. Creating a vector of integers and calculating its sum and mean
